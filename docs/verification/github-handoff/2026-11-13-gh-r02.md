## 保留人工內容的驗證

在 #1 的區塊之前加入一段人工筆記、之後加入一行補充連結，再對區塊執行 update。以
`gh issue view 1 --json body` 取得 GitHub 實際儲存的正文比對：更新後的正文與上傳的
檔案逐字相同，區塊外內容的 sha256 前 16 碼在更新前後都是 `38a8124b757978cf`。

過程中發現一個讀取陷阱：以 `--jq .body` 輸出正文時，`gh` 會多加一個結尾換行。若用這種
輸出做讀取、修改、寫回，每次更新都會讓區塊外多出一個換行。這次以 JSON 讀回確認儲存內容
沒有被改變；契約第 11 節與兩個 Skill 已補上「從 JSON 解析正文」的說明。
